# Słodka Pani

Statyczna strona-wizytówka pracowni cukierniczej Słodka Pani z Konina.

## GitHub Pages

Repozytorium zawiera gotową statyczną stronę oraz workflow publikujący ją automatycznie po każdym pushu do gałęzi `main`.

Docelowy adres: <https://whitep4gess.github.io/Cukiernia/>

Jeśli Pages nie są jeszcze aktywne, w ustawieniach repozytorium wybierz **Settings → Pages → Source: GitHub Actions** i uruchom workflow ponownie.
